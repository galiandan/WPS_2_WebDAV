Vendored browser distributions for Markdown rendering and code highlighting.

These files are unmodified upstream release artifacts; versions, npm package integrity values, source paths and SHA-256 hashes are recorded in manifest.json. No Node build or runtime is required.

- marked: MIT, https://github.com/markedjs/marked
- DOMPurify: Apache-2.0 option of the upstream dual license, https://github.com/cure53/DOMPurify
- highlight.js: BSD-3-Clause, https://github.com/highlightjs/highlight.js

The complete upstream licenses are retained in each project subdirectory. The adapter renders with its own scoped theme styles; no upstream CSS is modified.
