# 范围与安全边界

## 研究对象

研究对象限定为本人学校提供的 WPS 企业会员账号，以及该账号在当前租户中已经能正常使用的文件和目录。适配器只复现网页端或官方客户端为该账号完成正常操作所需的请求。

## 明确不做的事情

- 不猜测或枚举文件 ID、用户 ID、租户 ID。
- 不修改请求来扩大权限，不移除或绕过鉴权、验证码、风控和分享密码。
- 不读取浏览器开发者工具中与本实验无关的第三方请求。
- 不把 Cookie、Authorization、刷新 Token、签名 URL、客户端密钥或完整响应原文提交到 Git、Issue 或聊天中。
- 不对 WPS 服务做并发扫描、压力测试或大规模遍历。

## 测试数据

建议在本人网盘内新建一个专用目录，并使用不含隐私的测试文件，例如随机生成的几 KB 文本文件。每个实验使用唯一前缀，实验结束后由本人在网页端清理。

建议保留以下关联信息，但不要保留认证值：

- 网页端显示的目录和文件名。
- 操作发生的大致时间。
- 文件大小、扩展名和 UI 中显示的结果。
- 请求的 method、脱敏 URL、状态码、Content-Type 和 JSON 字段名。
- Token 的字段名、是否有过期时间以及刷新触发条件；不记录 Token 值。

## 证据等级

- `observed`: 在本人账号的一次或多次抓包中直接看到，并且与 UI 操作相符。
- `reproduced`: 使用本项目原型在本人账号中重放成功，并验证结果。
- `inferred`: 根据多个请求推断，但还没有单独实验确认。
- `unknown`: 尚未观察到，不能当作 API 事实使用。

所有 WPS 相关结论必须写入 `docs/findings.md`，注明证据等级、实验编号和观察时间。
