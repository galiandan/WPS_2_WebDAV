# WPS Drive 前端设计

## 视觉方向

参考 OpenList / OneList 的简洁文件浏览方式，自行实现页面结构与样式。使用系统字体、中性背景和蓝色主操作，不依赖外部字体服务。文件名、路径和操作是首屏的主要内容。

浅色模式使用灰白背景 `#f7f8fa`、白色面板和蓝色 `#1677ff`；深色模式使用 `#14171c` 背景、`#1c2027` 面板和浅蓝色 `#69aaff`。跟随系统与手动主题均可用。正文保持清晰对比，文件类型以柔和的彩色线条图标区分。

## 布局

- 顶栏：品牌、低调版本号、连接状态、刷新、设置与退出。
- 桌面：最大 1280px 的居中文件浏览器，空间导航为可横向滚动的一排按钮；标题、路径、搜索和文件面板按阅读顺序排列。
- 平板与手机：空间导航收进抽屉。搜索独占一行；次要文件属性收进文件名下方，操作保持触摸尺寸。
- 文件面板：轻边框、低阴影，名称列优先分配空间；列表和网格共享文件类型图标及操作菜单。
- 登录：采用 OpenList 的浅蓝／深蓝背景、两角蓝色曲线和 364px 居中表单，品牌与标题并排；用户名、密码输入框下方为清空／登录按钮，底部提供密码、Passkey 和主题切换。小屏幕留出 20px 边距，矮屏允许滚动；保留两步验证，登录过渡 180ms。背景 SVG 改编自 [OpenList-Frontend](https://github.com/OpenListTeam/OpenList-Frontend/tree/4520f96204408982a563e6a075adc020bac5dccb/src/pages/login)，MIT 许可及版权说明保存在 [许可证文件](licenses/OpenList-Frontend-MIT.txt)，并嵌入 HTML 随二进制分发。

## 空间切换

点击后立即更新空间高亮、路径与标题；未缓存的目录只显示加载占位，已缓存的目录立即呈现。导航按钮在空间名称和路径不变时保持原节点，避免焦点丢失。加载图标反映当前空间的读取状态，连续切换只接受最后一次导航的响应。

30 秒内的目录缓存直接复用，过期缓存先显示再刷新；手动刷新和变更后的失效逻辑继续生效。缓存命中不能证明 WPS 已恢复连接。

## 版本更新

点击顶栏版本号，在顶栏下方打开约 304px 宽的小浮层，无全屏遮罩，不锁定页面焦点。显示当前版本、检查结果、更新日志与更新操作。

打开及手动重新检查都跳过服务端检查缓存。只有确认存在更新时，按钮才执行更新 POST。检查中、下载中及重启中保留明确状态；服务恢复后沿用原来的健康检查与自动重载流程。

再次点击版本号、点击外部、焦点离开或按 Esc 均收起浮层。Esc 与关闭按钮将焦点还给版本号；点击外部不抢走目标的焦点。小屏幕保持左右至少 12px 间距，内容过长时在浮层内滚动。

## 交互与可访问性

保留目录导航、搜索、排序、列表／网格、上传、下载、预览、重命名、移动、删除、存储设置和登录安全功能。空目录、错误、加载及上传进度有独立反馈。键盘焦点可见，按钮有名称，状态文本通过 live region 播报；减少动态偏好下关闭非必要动画。

## 验证

不需要启动本地服务即可使用浏览器请求拦截提供模拟 API 和本地静态资源，验证不同视口、主题、目录操作和更新浮层。Go 构建将页面、脚本与样式嵌入可更新的二进制，现有 ETag 机制在升级后重新验证资源。
