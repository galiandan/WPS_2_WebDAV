# WPS WebDAV 前端设计语言

> 本文是当前前端视觉、布局、交互和动效的唯一设计依据，不包含实现代码，不增加需求之外的产品功能。

## 1. 设计主张：云上琉光

这是一个每天都可以打开、长时间使用的云盘文件工作台。第一眼清爽，仔细看有光泽、有层次，操作起来轻盈而明确。

“简约”来自清晰的结构、稳定的工具位置和克制的信息数量；“不简单”来自完整的状态设计、细腻的材质和连续的交互反馈；“华丽”通过精确的排版、局部透光与流畅的状态过渡表达。

动画应当贯穿整个使用过程：按钮会回应，目录切换有方向，视图变化有衔接，上传有节奏，完成有收束。静止时页面安静，操作时界面鲜活。

### 1.1 四条设计原则

- **文件是主角。** 名称和目录关系优先于装饰，首屏直接呈现文件工作区。
- **精致集中在细节。** 使用细边框、短阴影、小面积高光和准确对齐，不铺设大面积特效。
- **动作解释变化。** 位移表达导航，形态变化表达状态，渐显表达信息到达。
- **反馈服从事实。** 已提交、处理中、已完成必须清楚区分，动画不能提前宣布成功。

### 1.2 视觉边界

- 不做营销首页，不放宣传口号、功能介绍或巨型欢迎区域。
- 不把文件管理界面做成统计仪表盘，不增加容量图、活跃度图或无依据的数量指标。
- 页面采用连贯的工作台结构，侧栏、工具栏、文件区不分别装进悬浮卡片。
- 玻璃质感只用于少量浮层；大面积阅读区保持实色与高可读性。
- 不使用背景光球、粒子雨、持续闪烁、鼠标拖尾或大面积彩色渐变。
- 不新增收藏、最近访问、分享、回收站、在线编辑、批量操作或权限管理入口；TXT 在线浏览只作为文件菜单中的轻量只读能力。

## 2. 色彩与材质

### 2.1 主色关系

以中性白和石墨黑构成空间，翡翠绿负责主要操作，少量暖珊瑚与蓝色用于语义和文件类型。通过冷暖对照形成精致感，避免整页都是同一种颜色。

主色只占少量视觉面积。大部分文字、分隔线、表面和图标使用中性色，文件图标保留必要的类型色。

### 2.2 双主题色板

| 用途 | 浅色主题 | 深色主题 | 使用规则 |
| --- | --- | --- | --- |
| 页面底色 | `#F5F7F8` | `#121517` | 整个工作台的底层背景 |
| 主工作表面 | `#FFFFFF` | `#1A1F22` | 文件区、输入框、对话框 |
| 次级表面 | `#EEF2F3` | `#242B2F` | 悬停、分段控件底座、次要区域 |
| 主文字 | `#182126` | `#F1F5F6` | 文件名、标题、主要操作 |
| 次文字 | `#526169` | `#B1BEC4` | 路径、时间、大小、说明性状态 |
| 弱文字 | `#65737B` | `#97A6AD` | 非关键辅助信息，仍需满足可读性 |
| 装饰分隔线 | `#E0E6E9` | `#343F45` | 表格、区域边界，不单独承担控件识别 |
| 控件边界 | `#7B8991` | `#819199` | 需要靠边界辨认的输入框和控件 |
| 主操作 | `#087F70` | `#5AD9BB` | 上传、确认、当前激活项 |
| 主操作文字 | `#FFFFFF` | `#102820` | 放在主操作实色背景上 |
| 选中底色 | `#E5F5F0` | `#203C35` | 当前文件、当前导航项 |
| 信息 | `#245FBC` | `#8EBBFF` | 信息提示、部分文件类型 |
| 警告 | `#946000` | `#F0C36D` | 覆盖、未配置、连接过期 |
| 错误与危险 | `#BA3948` | `#FF97A2` | 删除、操作失败、阻断错误 |
| 暖色点缀 | `#C65D43` | `#F29E86` | 演示文稿等少量类型图标 |

禁止把装饰分隔线当成输入框唯一的可见边界。普通文字对比度至少为 4.5:1，必要的控件边界、状态图标和焦点指示至少为 3:1，最终以实际前景与背景组合验收。

状态永远同时使用图标和文字，不以绿点、红点或颜色深浅单独传达含义。

### 2.3 材质层级

- **工作层：** 实色背景、细分隔线，无背景模糊，保证大目录滚动时稳定清晰。
- **浮层：** 菜单与上传抽屉允许轻微透光，背景模糊仅作增强；不支持时使用同色不透明表面。
- **确认层：** 对话框采用实色表面、细描边和柔和阴影，遮罩降低背景存在感。
- **操作高光：** 主按钮上缘可以有极细亮边，悬停时明度轻微提高，禁止循环扫光。

阴影只用于真正浮在内容之上的菜单、提示、抽屉和对话框。文件列表不加阴影，网格文件项只允许极轻的悬停层次。

## 3. 字体、尺寸与图标

### 3.1 排版

使用设备原生无衬线字体与系统中文字体，不依赖外部字体服务。界面字距统一为 0，不使用随视口连续变化的字号。

| 文本角色 | 字号 / 行高 | 字重 | 应用位置 |
| --- | --- | --- | --- |
| 登录名称 | 28 / 36 px | 600 | 登录页的云盘名称 |
| 当前目录标题 | 22 / 30 px | 600 | 文件工作区主标题 |
| 对话框标题 | 18 / 26 px | 600 | 删除、移动、设置等浮层 |
| 正文与文件名 | 14 / 22 px | 400 或 500 | 列表、表单、按钮 |
| 次级信息 | 13 / 20 px | 400 | 时间、大小、路径补充 |
| 紧凑标记 | 12 / 18 px | 500 | 简短状态与类型标记 |

移动端表单输入文字至少为 16 px，避免输入时意外缩放。长名称允许换行或省略，并提供可通过键盘和触摸到达的完整名称展示方式。

文件大小、上传速度、百分比使用等宽数字，进度变化时不挤动相邻内容。

### 3.2 间距与形状

- 基础间距使用 4、8、12、16、24、32、48 px。
- 输入框与按钮圆角为 6 px，菜单、文件网格项、抽屉及对话框圆角不超过 8 px。
- 桌面主要控件高 36 px，输入框高 40 px；触摸设备交互目标至少为 44 × 44 px。
- 图标按钮保持固定宽高；加载、悬停、提示出现时不得改变尺寸。
- 列表行默认高 48 px，触摸设备至少为 56 px。
- 进度条可使用圆端；不把普通状态文字都装进胶囊标签。

### 3.3 图标与文件视觉

使用同一套 Lucide 风格线性图标，常规尺寸为 18 或 20 px，线宽保持一致。工具使用熟悉的符号：上传、下载、刷新、上一层、新建文件夹、网格、列表、更多、退出。

文件类型用“轮廓 + 小范围颜色 + 类型标识”区分：文件夹使用柔和金色，文档使用蓝色，表格使用绿色，演示使用珊瑚色，图片使用青色，压缩包与未知文件使用中性色。不得只靠颜色判断类型。

网格中的文件视觉使用文件类型图形，不默认请求文件正文生成缩略图，也不暗示存在在线预览能力。没有类型信息时使用通用文件图标。

所有图标按钮具有无障碍名称和悬停提示。提示也在键盘聚焦时出现；移动端菜单显示图标与文字，不依赖悬停。不可用操作仍能通过邻近说明或可访问描述解释原因。

## 4. 页面骨架与信息层级

### 4.1 桌面工作台

整体由顶栏、左侧导航、主工作区和按需出现的上传抽屉组成，区域之间用细线与底色区分。

| 区域 | 尺寸建议 | 内容与优先级 |
| --- | --- | --- |
| 顶栏 | 高 56 px | 左侧云盘名称，右侧 WPS 状态、状态刷新、主题、设置、退出 |
| 左侧导航 | 宽 208 px | 根目录入口、实际获取到的空间入口；空间列表较长时独立滚动 |
| 主工作区边距 | 24 px | 大屏最多增至 32 px，不把文件区限制成窄内容列 |
| 路径区 | 最小高 40 px | 返回上一级、可点击面包屑；根目录始终可到达 |
| 工具区 | 最小高 56 px | 当前目录名、当前目录搜索、排序、视图切换、新建文件夹、上传 |
| 文件区 | 占据剩余空间 | 默认列表视图；表头稳定，文件内容可滚动 |
| 上传抽屉 | 宽 360 px | 从工作区右侧出现，提供展开、收起和队列状态 |

工具区可分为上下两行，不能为了维持单行而压缩文件名或隐藏关键操作。上传是主要按钮；新建文件夹为带提示的图标工具；排序使用菜单；列表与网格使用图标分段控件。

抽屉展开时，宽度足够的桌面界面重新分配文件区宽度；空间不足时使用覆盖式抽屉与遮罩，避免把文件列挤到不可读。上传进行中始终保留紧凑的队列入口。

侧栏只呈现真实存在的导航内容。网页根目录展示登录时选中的全部 WPS 空间，例如 A 和 B；WebDAV 根目录是独立配置的单个子树，不影响网页空间的浏览范围。

网页可以直接在侧栏切换 A、B 空间；WebDAV 客户端不会看到空间切换层，只能访问当前唯一映射，例如 A/web。真实文件夹使用普通文件夹图标。

### 4.2 平板与移动端

| 宽度 | 结构变化 |
| --- | --- |
| 1200 px 及以上 | 完整侧栏、完整文件列，可按空间容纳上传抽屉 |
| 768 至 1199 px | 侧栏收起为抽屉，工具栏按需分行，保留核心文件列 |
| 低于 768 px | 单列工作区，页面边距 16 px，导航与上传使用覆盖式面板 |

手机顶栏只放云盘名称、WPS 状态入口和全局菜单。退出登录位于全局菜单一级并直接可见，不埋入设置子页面。

手机工具区优先显示搜索、上传、新建文件夹与视图入口，排序可进入工具菜单。文件列表每项采用两行：第一行文件名，第二行类型、大小和时间，右侧固定更多操作按钮。

面包屑空间不足时，中间路径折叠进菜单，保留根目录和当前目录。当前目录名可在独立标题处换行显示，不让超长名称挤走导航按钮。

手机网格通常为两列；在窄屏或系统大字体下退为一列。不得为保留列数持续缩小文字。

移动端面板使用底部安全区域，弹出键盘后输入框和确认按钮仍可到达。页面本身不产生横向溢出。

## 5. 登录页与会话

### 5.1 登录页构图

使用全页实色背景，中间偏上的无框表单，宽度上限 360 px。云盘名称以 28 px 标题出现，下方依次为用户名、密码和登录按钮，不再包一层装饰卡片。

背景的精致感来自表单周围的留白、输入框边缘和按钮上缘高光。可使用与产品一致的小型云盘标记，不加入无关插画或大幅宣传内容。

用户名与密码使用持续可见的标签，密码输入支持显隐切换。错误信息固定出现在字段附近或提交按钮上方，不通过大幅移动表单来显示错误。

### 5.2 登录状态

- **检查会话：** 保持页面基础背景与简短“正在检查登录状态”，避免先显示登录页再突然跳转。
- **输入中：** 聚焦描边平滑增强，密码显隐按钮不挤动输入区。
- **提交中：** 按钮尺寸不变，显示进度图标与“正在登录”，阻止重复提交。
- **凭据错误：** 显示“用户名或密码错误”，保留用户名，允许修正后重试。
- **服务不可用：** 显示“服务暂时不可用，请稍后重试”。
- **网络错误：** 显示“网络连接失败，请检查连接后重试”。
- **成功：** 表单柔和淡出，工作台接续出现，不播放冗长的成功过场。
- **会话过期：** 返回登录页并显示“登录已过期，请重新登录”；重新登录后尽量恢复原目录，不自动重新提交写操作。

登录成功状态由会话检查结果决定，使用 HttpOnly 会话 Cookie。界面不提供记住密码、注册、找回密码、切换账号或修改密码功能。

## 6. WPS 连接状态语言

网页会话与 WPS 连接是两个独立状态。网页能够打开、用户已经登录，都不能直接展示“WPS 已连接”。

桌面顶栏持续显示“图标 + WPS 状态文字”，点击可打开紧凑状态面板，其中显示网页服务状态和 WPS 状态，并提供刷新按钮。手机采用更短的状态文字，进入面板后显示完整原因。

| 状态 | 视觉与文案 | 工作区行为 |
| --- | --- | --- |
| 正在检查 | 中性进度图标；“正在检查 WPS” | 未取得可用结果前，不宣称已连接 |
| WPS 已连接 | 绿色勾选图标；“WPS 已连接” | 按目录权限开放操作 |
| WPS 尚未配置 | 警告图标；“WPS 尚未配置” | 内容区显示原因，不提供虚构的网页登录或配置入口 |
| WPS 登录已过期 | 警告图标；“WPS 登录已过期” | 禁用依赖 WPS 的操作；保留状态刷新与本地名称设置 |
| 没有权限访问当前空间 | 锁定图标；“当前空间无权限” | 限制当前空间，允许返回根目录或访问其他可用空间 |
| WPS 暂时不可用 | 错误图标；“WPS 暂时不可用” | 保留页面结构，提供重试 |
| WPS 返回格式异常 | 错误图标；“WPS 响应异常” | 使用可理解说明，不暴露原始响应 |
| 网络连接失败 | 断开图标；“网络连接失败” | 保留已显示的目录并标记未更新，提供手动重试 |

首次无法读取目录时，在内容区展示相应状态；已有内容后发生后台检查失败时，保留现有列表，在工作区上方显示紧凑提示条。缓存内容不可伪装成最新结果。

后台复查不反复替换整个页面，不周期性弹出相同通知。复查期间可以明确展示上次结果及“正在复查”，但上次成功不能覆盖已经确认的过期或失败状态。

## 7. 目录导航、搜索与文件展示

### 7.1 导航

点击空间或文件夹进入目录，点击文件名选中该项；下载通过明确的下载操作触发，避免暗示可打开在线编辑器。触摸与键盘行为保持一致。

根目录入口、上一级按钮、面包屑和浏览器前进后退指向同一套路径状态。URL 只表达可公开的目录路径，不包含凭据、令牌或下载签名。

进入子目录时，内容向左轻移并淡入；返回父目录时反向。点击跨层面包屑或恢复页面路径时采用短淡入，不制造多级连续飞行动画。

从子目录返回时尽量恢复之前的滚动位置和焦点。进入新目录后，上一目录的搜索条件不应默默隐藏新目录内容；默认清空当前目录搜索，历史返回可恢复对应目录当时的搜索状态。

### 7.2 列表视图

列顺序为名称、类型、大小、修改时间、操作。名称列吸收剩余宽度；大小右对齐，时间和操作列保持稳定。文件夹大小没有真实数据时显示短横线，不编造累计容量。

默认建议按名称升序、文件夹优先。后续沿用用户保存的排序方式，文件夹优先规则保持一致。

悬停时整行出现浅底色，右侧显示下载与更多操作。键盘聚焦时提供同等操作能力；触摸设备上的更多按钮常驻，不让关键操作只存在于悬停状态。

文件名过长时保留扩展名识别，完整名称可通过悬停、聚焦提示或操作面板查看。工具提示应换行，不超出视口。

普通选中和键盘焦点分开表达：选中使用浅主色底，焦点使用清晰外框。需求未包含多选，不默认放置批量选择复选框。

### 7.3 网格视图

网格项是允许使用卡片的重复文件单元，使用轻描边和最多 8 px 圆角，不在内部再嵌套卡片。

每项由固定比例的图标区、文件名区、元信息区和稳定的操作入口组成。桌面宽度建议为 156 至 192 px；根据容器可用宽度分配列数，项内结构不随悬停变化。

文件名默认展示两行，额外内容省略并可查看完整名称。图片文件仍可使用类型图标，本设计不要求读取正文或提供缩略图服务。

### 7.4 搜索与排序

搜索框文案为“搜索当前目录”，输入后过滤当前目录的文件名，匹配片段用低饱和背景突出，保留原文字对比度。提供清除图标，并支持键盘操作。

搜索、排序和视图切换只更新文件区，工具栏不重新入场。排序使用选项菜单，明确展示名称、大小、修改时间及升序、降序；当前选项有勾选标记。

只保存主题、视图和排序等非敏感偏好。目录预加载与缓存仅涉及元数据；刷新及成功的上传、新建、删除、重命名、移动之后，相关目录需要重新确认最新内容。

### 7.5 内容区状态

| 场景 | 内容呈现 | 可用动作 |
| --- | --- | --- |
| 首次加载 | 与目标视图一致的骨架，显示少量占位行或网格项 | 保留导航 |
| 原目录刷新 | 保留旧列表，顶部出现细进度指示及“正在刷新” | 避免重复刷新 |
| 空目录 | 小型文件夹图标与“此文件夹为空” | 权限允许时显示上传、新建文件夹 |
| 搜索无结果 | 搜索图标与“没有找到匹配的文件” | 清除搜索 |
| 无权限 | 锁定图标与“没有权限访问此目录” | 返回上一级或根目录 |
| 路径不存在 | 路径图标与“此目录不存在或已被移动” | 返回上一级或根目录 |
| 读取失败 | 错误图标与简明原因 | 重试 |

状态区域使用内容区中的自然留白，不做巨型插画或独立悬浮卡片。根目录没有可用空间时，按实际状态说明未配置或没有可用空间，不诱导用户在虚拟根目录新建空间。

大目录加载时导航和工具栏仍可响应。骨架只覆盖可见范围，不给所有文件编排逐项入场。

## 8. 文件操作交互

### 8.1 上传与全页拖入

上传按钮在支持写入的实际目录中可用。根目录已经是当前 WPS 空间的实际映射目录，可以直接上传和新建文件夹。

当系统文件拖入网页时，工作区出现全页接收遮罩：细主色边框、轻微底色和中央上传图标。文案明确显示“上传到：当前目录”，路径过长时分行。

只对外部文件拖入显示该状态，普通文字拖动、文件项点击或选中不得误触发。指针经过内部控件时遮罩保持稳定，离开页面后平滑退场。

拖放落点确定后，队列记录当时的目标目录。上传中切换目录不会改变已排队文件的目的地，队列项可查看完整目标路径。

上传抽屉采用连续队列行，每行展示文件名、状态、真实进度、已上传大小与总大小、速度和适用操作。长文件名不挤压进度数字与取消按钮。

| 队列状态 | 表现 | 操作 |
| --- | --- | --- |
| 等待 | 中性时钟图标与“等待上传” | 取消该项 |
| 上传中 | 真实百分比、大小、速度和进度条 | 取消当前上传 |
| 正在确认 | 数据发送完毕后显示“正在确认上传结果” | 依据实际能力提供操作，不假装已经成功 |
| 成功 | 勾选图标与“上传完成” | 保留记录，允许收起队列 |
| 失败 | 错误图标、失败原因 | 在条件恢复后手动重新上传 |
| 正在取消 | 状态稳定显示，阻止重复取消 | 等待取消结果 |
| 已取消 | 停止图标与“已取消” | 保留明确结果 |

多个文件按顺序上传。百分比必须来自实际进度；不能测得进度或速度时显示不确定进度或“计算中”，不生成平滑但虚假的数字。

同名文件出现覆盖确认，显示冲突文件名以及“覆盖”“取消此项”。默认焦点落在非破坏性操作，不默认勾选批量覆盖。同名文件夹冲突时直接说明无法覆盖，不显示可执行的覆盖按钮。

关闭上传抽屉只收起界面，不取消上传。当前目录上传成功后合并刷新；上传过程中不因每次进度更新反复刷新目录。已经离开的目录仅使对应缓存失效，不强迫用户跳回。

### 8.2 下载

文件行、网格操作菜单提供下载入口。请求准备期间按钮显示短加载反馈，交给浏览器下载后结束该反馈；不显示网页无法得知的下载完成百分比或“下载成功”。

文件不存在、权限不足、WPS 过期或服务异常时显示对应错误。签名下载地址只在必要流程中短暂使用，不长期保存，也不在错误详情中展示。大文件由浏览器正常下载，不以全量前端内存读取换取自制进度。

### 8.2.1 TXT 在线浏览

`.txt` 文件在更多操作菜单中提供“在线浏览”。预览以纯文本方式显示，使用独立滚动区域，不执行文件内容中的 HTML 或脚本；服务端默认最多返回前 2 MiB，超出后显示截断提示并保留“下载完整文件”入口。预览失败时保留对话框和错误信息，不伪装成空文件。

### 8.3 新建文件夹与重命名

使用紧凑表单对话框：标题、名称字段、行内错误、取消、确认。打开后焦点进入输入框，支持回车提交和 Escape 取消。

重命名预填原名称，文件默认选中不含扩展名的名称主体，文件夹选中全名。空名称、非法名称和冲突就地提示；长度限制依据现有后端约束，不在设计中编造具体上限。

提交期间锁定重复写入。服务确认成功后才更新文件列表；失败时保留输入内容和原项目，便于修正。

### 8.4 移动

桌面使用宽度上限 560 px 的目标目录对话框，手机使用接近全屏的面板。顶部显示被移动项目名称，中部为目标面包屑与可进入的目录，底部明确显示目标位置和“移动到此处”。

当前位置不能作为无意义的移动目标；自身和自身子目录不可选，并有明确说明。可以导航到其他实际可写目录，跨空间是否可用由后端能力与权限决定，界面不预先承诺。

目标目录加载、空目录和读取失败都在选择区内呈现，失败时保留面包屑与返回操作。移动成功后再从源目录移除项目并刷新；失败时保留源列表内容。

### 8.5 删除

删除放在更多菜单末尾，与普通操作分隔，使用危险色图标和文字。删除确认必须显示项目名称；文件夹提示其包含内容会受到影响，不承诺可以恢复，也不虚构回收站。

对话框以“取消”为默认焦点，“删除”为明确的危险按钮。确认之前可以直接取消；确认提交之后，不使用一个仍标为“取消”的按钮暗示能撤销已发送的删除请求。

异步删除必须分为“正在提交”“正在删除”“删除完成”三个阶段。收到受理响应后，项目仍留在列表中并标记“正在删除”，限制与该项冲突的操作。服务确认完成后，项目才短暂淡出并刷新列表。

删除失败时恢复可操作状态并显示原因。暂时无法确认结果时显示“删除结果待确认”，提供刷新确认结果的方式，不以绿色通知提前宣告成功。

用户关闭进度浮层不会终止已经提交的服务端操作，结果仍应通过原项目状态或持续通知呈现。确认完成前不自动重复提交删除。

## 9. 云盘名称、主题与本地偏好

设置使用一个紧凑面板，不扩展成复杂后台。包含云盘显示名称和主题选择；视图、排序仍在文件工具栏中设置。

名称输入预填当前值。空名称、过长或非法输入使用行内校验。保存中按钮显示明确状态；成功之后，网页标题、顶栏名称、根目录标题、面包屑根节点和虚拟根目录名称一起更新。

保存失败保留原有显示名称和当前编辑内容。WPS 不可用时，本地显示名称仍可修改；不把该操作描述为重命名远端文件夹。

主题采用“跟随系统 / 浅色 / 深色”三个带图标的分段选项，当前选择有清晰的选中底色。顶栏主题入口可快速打开同一组选项，不能在不同位置出现不一致的选择状态。

主题切换以短暂的表面、文字与边框颜色过渡完成，不使用全屏圆形扩散或闪白。跟随系统模式随系统变化更新，手动选择则保持用户偏好。

## 10. 动效体系

### 10.1 总体节奏

动效覆盖主要交互，但每次动作最多突出一个主运动区域，其他区域以轻微颜色或透明度变化响应。页面可以频繁回应操作，不需要持续自行表演。

动画不等待网络后再启动：操作发生时立即反馈，数据到达后完成状态衔接。真实数据和可用控件不应为等待入场动画而延后出现。

| 节奏 | 时长 | 用途 |
| --- | --- | --- |
| 即时反馈 | 90 至 120 ms | 按压、图标明度、开关触发 |
| 细节过渡 | 140 至 180 ms | 悬停、选中、工具提示、聚焦变化 |
| 常规切换 | 200 至 260 ms | 搜索结果、菜单、短距离目录过渡 |
| 结构变化 | 280 至 360 ms | 抽屉、对话框、列表与网格切换 |
| 完成收束 | 320 至 420 ms | 上传成功、删除完成、登录进入工作台 |

进入采用快速响应、缓慢落定的曲线；退出略快于进入；进度变化采用连续的线性或柔和插值。除轻量视图控件外，不使用明显回弹，更不让表格行弹跳。

### 10.2 动效编排表

| 场景 | 动作设计 | 边界 |
| --- | --- | --- |
| 登录初次显示 | 标题与表单从下方 8 px 淡入，间隔约 40 ms | 总时长不超过 360 ms，输入立即可用 |
| 登录成功 | 表单淡出，工作台由 6 px 偏移回到原位 | 不额外展示全屏成功页 |
| 图标工具悬停 | 图标颜色加深、底色渐显 | 160 ms，无尺寸变化 |
| 主按钮按压 | 表面亮度变化，内容最多下移 1 px | 100 ms，按钮边界保持固定 |
| 输入框聚焦 | 描边与焦点环平滑出现 | 140 ms，不移动输入文字 |
| 字段校验失败 | 错误图标与文案短淡入，边界变为错误色 | 不默认左右抖动表单 |
| 菜单打开 | 从触发位置附近淡入并移动 4 px | 160 ms，不影响布局 |
| 面包屑展开 | 隐藏路径菜单短距离展开 | 180 ms，焦点进入菜单 |
| 进入与返回目录 | 内容沿方向移动最多 12 px，并交叉淡入 | 220 ms，旧目录退出前即锁定路径归属 |
| 列表首次到达 | 首屏可见行轻微淡入，最多 8 行参与错峰 | 每行间隔 16 ms，全部在 320 ms 内结束 |
| 列表与网格切换 | 可见项目图标与标题短距离过渡，或整体交叉淡入 | 280 至 320 ms；无法稳定对应时使用淡入 |
| 搜索结果更新 | 结果集合交叉淡入，命中背景同步出现 | 160 ms，不逐字播放，不移动搜索框 |
| 排序改变 | 可见项目在新位置之间平滑重排 | 220 ms；大量项目或远距离重排改用短淡入 |
| 选中项目 | 选中底色与边界渐显 | 140 ms，不把整行抬起 |
| 骨架加载 | 中性明暗缓慢变化 | 周期约 1500 ms，范围仅限内容区 |
| 刷新状态 | 刷新图标匀速转动，完成后自然停下 | 只在真实请求期间循环 |
| 全页拖入 | 遮罩淡入，接收边框出现，中央图标上移 4 px | 180 ms，无持续呼吸缩放 |
| 文件进入队列 | 对应队列行淡入，上传入口短暂强调一次 | 220 ms，不用飞行轨迹跨越整页 |
| 上传中 | 进度条依据真实数值平滑前进，活动图标低幅运动 | 数值不超前，不额外延迟取消响应 |
| 上传完成 | 进度图标切换为勾选，进度色轻微收束 | 360 ms，仅发生一次 |
| 新建与重命名完成 | 目标项目出现一次浅主色强调后回落 | 400 ms，不导致列表自动跳到远处 |
| 删除完成 | 已确认删除的可见行淡出，再平滑收拢空位 | 淡出 140 ms，收拢 180 ms |
| 抽屉打开 | 沿边缘滑入最多 24 px，遮罩同步淡入 | 300 ms，不从屏幕外长距离飞入 |
| 对话框打开 | 从下方 8 px 淡入，比例从 98% 到 100% | 240 ms，关闭约 180 ms |
| 通知出现 | 沿所在边缘移动 6 px 并淡入 | 180 ms，不连续弹跳 |
| 主题切换 | 背景、文字、边框同步换色 | 220 ms，切换期间仍保持文字可读 |

### 10.3 连续操作与性能

- 快速切换目录时，新操作接管当前动画，过时响应不得覆盖当前目录。
- 连续搜索与排序采用最新状态，不把每次输入都排成动画队列。
- 文件区只为当前可见项做入场，滚动中新出现的普通行不重复播放仪式化动画。
- 大量目录项的重排优先采用短淡入，避免全表同时运动。
- 动画优先改变透明度和位移。模糊、阴影和布局尺寸变化限制在小范围与短时间内。
- 上传百分比更新不会导致文件列表重新布局，数字宽度、进度条高度和操作按钮位置始终稳定。
- 非活动页面暂停装饰动画；上传、状态确认等业务状态继续按实际结果更新。
- 低性能设备可降为淡入过渡，所有功能和状态仍完整可用。

### 10.4 减少动态模式

尊重系统的减少动态设置，无需用户额外寻找开关。

关闭方向位移、缩放、错峰入场、循环骨架明暗及行重排动画，保留即时状态更新与最多 100 ms 的必要淡入。等待使用稳定图标配合文字，上传进度仍按真实数值更新。

减少动态不会隐藏加载状态，也不会移除成功、失败、焦点和取消反馈。禁止闪烁或高频明暗变化。

## 11. 通知、错误与反馈层级

反馈按影响范围就近出现：字段问题放在字段旁，目录问题放在文件区，单文件问题放在对应项目或队列行，全局连接问题放在状态区。

普通成功通知约 3 秒自动收起；普通失败通知约 6 秒，支持手动关闭，悬停或聚焦期间暂停计时。需要用户决策、持续阻断或涉及未确认写操作的错误必须保留在对应区域，不能随通知一起消失。

桌面通知位于右下方并避让上传抽屉，移动端位于底部安全区域上方。最多同时显示三条，对同一队列或重复连接错误合并反馈。

| 错误语义 | 建议文案 | 后续行为 |
| --- | --- | --- |
| 网页会话无效，通常为 401 | 登录已过期，请重新登录 | 返回登录页，保留可恢复的非敏感路径 |
| WPS 登录过期 | WPS 登录已过期 | 更新 WPS 状态，依语义处理，不误清除仍有效的网页会话 |
| 403 | 没有权限执行此操作 | 保留当前内容，限制对应操作 |
| 404 | 文件或目录不存在 | 提供刷新或返回上一级 |
| 409 | 名称已存在 | 聚焦名称输入或进入覆盖确认 |
| 413 | 文件过大，无法上传 | 队列项显示原因；有可靠限制值时再展示具体数值 |
| 507 | 空间不足或已达到服务限制 | 保留失败项目与原因 |
| 502 / 503 | WPS 或网页服务暂时不可用 | 按实际错误来源显示文案并提供重试 |
| 网络失败 | 网络连接失败，请重试 | 保留界面，网络恢复后允许手动重试 |

错误判断应结合现有接口的错误含义，不能只按一个状态码把所有上游异常都当成网页登录失效。

界面不展示 Cookie、密码、CSRF、Token、签名 URL 或上游原始响应。不能确定原因时使用准确但有限的说明，例如“暂时无法读取目录，请重试”，不编造诊断。

## 12. 键盘、触摸与可访问性

- 主要焦点顺序为导航、路径、搜索与工具、文件列表、上传入口；焦点不得进入隐藏的菜单或抽屉。
- 文件项具有清楚的名称、类型和适用操作，键盘用户可进入文件夹并打开操作菜单。
- 所有图标工具在悬停与聚焦时都有提示，不在页面常驻一排快捷键说明。
- 对话框打开时将焦点移入，保持焦点在对话框内；关闭后返回触发控件，触发项已删除时移到相邻项或列表标题。
- Escape 关闭菜单与可取消的对话框；对于已提交操作，关闭显示层不被解释为撤销请求。
- 表单支持回车提交，同时受名称校验和防重复提交规则约束。
- 状态提示可被辅助技术感知；上传按关键进度节点播报，不按每个百分比更新连续打断用户。
- 触摸交互不要求双击、悬停或拖拽；所有拖拽上传能力都有文件选择按钮作为等价入口。
- 在 200% 缩放、窄屏与大字体下，文字可重排，按钮可分行，确认操作不被截断。
- 固定工具栏、通知、上传面板与软键盘不得遮挡当前输入框或关键确认按钮。

## 13. 需求与设计边界

本设计围绕现有认证、状态、目录、元数据、下载、上传、文件夹、文件操作与设置接口展开，不要求新增接口、第三方登录或浏览器扩展。

网页登录只使用安装时配置的适配器账号密码。WPS 连接信息由现有流程同步；普通网页不提供 Cookie 输入、导入或查看界面，也不调用仅供登录脚本使用的会话导入接口。

全部字体、图标与必要视觉资源应能随前端资源一同交付，并满足 Go `embed` 的单二进制分发约束。设计不依赖外部图片、外部字体、在线素材服务或第三方身份系统，HTTP 和 HTTPS 下均应成立。

文件正文不作为目录缓存、图标识别或转场的前置条件。下载、上传进度、异步删除结果和名称限制均以现有能力与真实服务结果为准。

## 14. 设计验收标准

### 14.1 简约但不简单

- 首屏能快速识别云盘名称、当前目录、WPS 状态和上传入口。
- 主工作区连续完整，不出现多层卡片包裹，文件名有充分空间。
- 空目录、无结果、无权限、路径不存在和服务异常各有明确视觉状态。
- 列表、网格、导航、表单与操作菜单共享一致的尺寸、色彩和焦点语言。

### 14.2 华丽但不过于花哨

- 精致感来自材质、排版和过渡，不依赖大型背景装饰。
- 浅色清透，深色清晰；深色主题不变成大面积深蓝或紫色。
- 主色、类型色与语义色各有职责，色彩不会抢过文件内容。
- 页面静止时没有持续吸引注意的装饰动画。

### 14.3 动画充足且可信

- 登录、聚焦、导航、搜索、排序、视图切换、拖入、上传、弹层、通知与主题切换均有定义明确的反馈。
- 用户连续操作时，动画可接续、可打断，不形成等待队列。
- 上传不伪造进度，删除不提前消失，下载不假报完成。
- 大目录、低性能设备和减少动态模式下，仍能清晰辨认每一步的状态。

### 14.4 完整状态交付

后续视觉稿至少覆盖浅色与深色桌面工作台、手机文件列表、手机网格、登录错误、WPS 异常、上传队列及覆盖冲突、移动目录选择、删除等待、云盘名称设置，并为同一组关键操作展示正常与减少动态两种动效说明。
