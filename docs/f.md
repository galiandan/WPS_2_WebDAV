# WPS WebDAV 前端功能需求

本文档面向前端重构和界面设计，只规定功能、状态和交互行为，不规定颜色、布局、组件样式或具体技术实现。

## 一、基本约束

- 这是 WPS 云盘的 Web 文件管理器。
- 前端必须兼容现有 Go 后端接口。
- 不需要注册功能。
- 不需要多用户功能。
- 唯一账号密码就是安装时设置的适配器 Basic Auth 账号密码。
- 网页登录和 WebDAV 使用同一组账号密码。
- 保留 HTTP 和 HTTPS 访问能力。
- 不使用浏览器扩展。
- 不依赖第三方登录服务。
- 不把 Cookie、密码、CSRF 或 Token 写入 URL、LocalStorage 或日志。
- 前端资源最终需要能够被 Go `embed` 编译进单个二进制。

## 二、登录功能

- 显示用户名输入框。
- 显示密码输入框。
- 提交登录。
- 登录成功后进入文件管理界面。
- 登录失败时显示错误原因。
- 区分账号密码错误、服务不可用和网络错误。
- 登录过程中禁止重复提交。
- 登录成功后使用 HttpOnly 会话 Cookie。
- 页面刷新后自动检查当前会话。
- 会话失效后自动返回登录页。
- 提供明显的退出登录按钮。
- 退出后清除当前网页会话并返回登录页。
- 不显示注册、找回密码、切换账号、多用户管理等功能。

## 三、WPS 连接状态

前端需要区分网页服务状态和 WPS 状态。

支持以下状态：

- 正在检查。
- WPS 已连接。
- WPS 尚未配置。
- WPS 登录已过期。
- 没有权限访问当前空间。
- WPS 暂时不可用。
- WPS 返回格式异常。
- 网络连接失败。

要求：

- 服务进程正常不代表 WPS 一定已连接。
- WPS 状态需要明显显示。
- WPS 状态异常时，文件操作按钮应适当禁用。
- 提供刷新状态的操作。
- 页面可定时检查 WPS 状态。
- WPS Cookie 过期时，不应误显示为“已连接”。
- 错误信息中不能显示 Cookie、CSRF、签名 URL 或上游原始响应。

## 四、空间和目录导航

- 显示当前 WPS 云盘根目录。
- 支持多个 WPS 空间。
- 多个 WPS 空间需要作为根目录下的虚拟文件夹显示。
- 空间名称必须来自登录脚本获取的数据，不能写死。
- 支持进入空间。
- 支持进入子文件夹。
- 支持返回上一级。
- 支持点击路径导航。
- 支持点击根目录返回首页。
- 支持浏览器前进和后退。
- 支持通过 URL 保存当前路径。
- 刷新页面后尽量恢复当前目录。
- 当前目录读取时显示加载状态。
- 目录为空时显示空目录状态。
- 无权限时显示明确的权限错误。
- 目录不存在时显示路径错误。
- 大目录加载时不能让页面看起来卡死。
- 支持目录预加载或缓存。
- 目录缓存需要在刷新、上传、删除、重命名、移动后失效。
- 不能缓存文件正文，只缓存目录元数据。

## 五、文件列表

每个文件或文件夹至少显示：

- 名称。
- 类型。
- 文件大小。
- 修改时间。
- 文件夹或文件图标。
- 可用操作。

支持：

- 列表视图。
- 网格视图。
- 列表和网格之间切换。
- 保存用户上次选择的视图。
- 文件类型图标识别。
- 长文件名完整显示或通过悬停查看。
- 文件名搜索。
- 搜索当前目录。
- 搜索结果高亮。
- 按名称排序。
- 按大小排序。
- 按修改时间排序。
- 升序和降序切换。
- 保存排序方式。
- 文件夹优先显示。
- 空目录、搜索无结果、读取失败分别显示不同状态。
- 加载时显示骨架屏或加载提示。

## 六、文件操作

### 下载

- 下载文件。
- 使用浏览器默认下载行为。
- 显示下载失败提示。
- 处理文件不存在、权限不足、WPS 过期和上游异常。
- 不把下载 URL 长期保存到前端状态。
- 大文件下载不能通过前端一次性读入内存。

### 上传

- 点击按钮选择文件。
- 支持多文件上传。
- 支持整个网页拖拽上传。
- 拖入文件后默认上传到当前目录。
- 显示当前上传文件名。
- 显示上传百分比。
- 显示已上传大小和总大小。
- 显示实时上传速度。
- 显示上传队列。
- 显示等待、上传中、成功、失败、取消等状态。
- 支持取消当前上传。
- 支持多个文件依次上传。
- 上传失败后显示具体原因。
- 同名文件需要询问是否覆盖。
- 同名文件夹不能被文件覆盖，并需要明确提示。
- 上传成功后刷新当前目录。
- 上传期间避免重复刷新和重复提交。
- 大文件上传时不能阻塞整个页面。

### 新建文件夹

- 在当前目录新建文件夹。
- 输入文件夹名称。
- 校验空名称和非法名称。
- 创建成功后刷新当前目录。
- 创建失败后显示错误。
- 处理同名文件和文件夹冲突。

### 重命名

- 文件和文件夹都支持重命名。
- 输入框需要填充原名称。
- 禁止空名称。
- 成功后刷新当前目录。
- 失败后保留原状态并显示错误。

### 移动

- 文件和文件夹都支持移动。
- 支持选择目标文件夹。
- 支持返回目标文件夹的上一级。
- 禁止移动到自身或自身子目录。
- 支持移动到当前目录以外的目录。
- 移动完成后刷新源目录。
- 目标目录读取失败时显示明确提示。
- 移动失败时不应误从列表中删除项目。

### 删除

- 文件和文件夹都支持删除。
- 删除前必须二次确认。
- 显示被删除项目名称。
- 删除成功后刷新当前目录。
- 删除失败后保留列表内容。
- 对 WPS 异步删除任务显示等待状态。
- 不允许用户误以为请求发送成功就已经删除完成。

## 七、云盘名称设置

- 读取当前适配器显示名称。
- 支持在网页中修改名称。
- 修改前显示当前名称。
- 校验空名称、过长名称和非法输入。
- 保存成功后同步更新网页标题、根目录标题、路径名称和虚拟根目录名称。
- 保存失败时显示错误。
- WPS 未连接时也允许修改本地显示名称。
- 不重命名 WPS 远端真实文件夹。

## 八、主题和本地偏好

- 支持跟随系统主题。
- 支持浅色主题。
- 支持深色主题。
- 支持主题切换。
- 保存主题选择。
- 保存列表/网格视图选择。
- 保存排序方式。
- 本地偏好中不得保存账号密码、Cookie、CSRF 或 WPS Token。

## 九、反馈和错误处理

- 所有网络请求都要有加载状态。
- 所有写操作都要防止重复提交。
- 成功操作显示简短反馈。
- 失败操作显示可理解的错误。
- 支持自动隐藏的通知。
- 支持手动关闭通知。
- 关键错误不能只显示 HTTP 状态码。
- `401` 要引导重新登录。
- `403` 要提示没有权限。
- `404` 要提示文件或目录不存在。
- `409` 要提示名称冲突。
- `413`/`507` 要提示文件太大、空间不足或达到限制。
- `502`/`503` 要提示 WPS 或服务暂时不可用。
- 网络恢复后可以手动重试。
- 页面不能因一次请求失败而整体白屏。

## 十、响应式和可访问性

- 支持桌面浏览器。
- 支持手机浏览器。
- 支持平板浏览器。
- 支持触摸操作。
- 支持键盘操作。
- 所有图标按钮必须有悬停提示。
- 所有图标按钮必须有无障碍名称。
- 输入框支持回车提交。
- 对话框支持取消和 Escape 关闭。
- 焦点顺序合理。
- 文字不能溢出或互相遮挡。
- 上传、删除、移动等危险操作必须容易辨认。
- 不能只依靠颜色表达成功、失败或警告状态。

## 十一、现有后端接口

认证接口：

```text
GET    /api/v1/auth/me
POST   /api/v1/auth/login
POST   /api/v1/auth/logout
```

文件和状态接口：

```text
GET    /api/v1/status
GET    /api/v1/entries?path=/
GET    /api/v1/metadata?path=/file
GET    /api/v1/download?path=/file
PUT    /api/v1/upload?path=/file
POST   /api/v1/folders?path=/folder
PATCH  /api/v1/entries?path=/file
DELETE /api/v1/entries?path=/file
GET    /api/v1/settings
PATCH  /api/v1/settings
```

`POST /api/v1/session/import` 只由 `wps_login.py` 用于同步 WPS Cookie、CSRF 和空间信息，普通网页不应调用。

## 十二、明确不需要实现的功能

- 注册账号。
- 多用户切换。
- 用户管理。
- 用户权限管理。
- 找回密码。
- 修改网页登录密码。
- 浏览器扩展。
- 在线编辑 Office 文档。
- WPS 账号密码登录。
- 前端直接读取 WPS Cookie。
- 前端保存 WPS Cookie 或 Token。
- 前端直接请求 `365.kdocs.cn`。
- 复杂的后台管理系统。
- 依赖第三方前端登录服务。
