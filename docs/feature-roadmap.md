# OpenList 功能对照与实现进度

这份清单记录本轮“按优先级完成可独立实现功能”的完整范围。表中版本记录各功能的代码归属；发布完成以对应 GitHub Release 的产物与 CI 验证为准。当前开发不需要真实 WPS 凭据。

| 顺序 | 功能 | 引入版本 | 实现边界 |
| --- | --- | --- | --- |
| 1 | 图片/PDF 预览 | v1.1.0 | 图片缩放、同目录切图；PDF 使用浏览器内置阅读器；复用认证和 Range 下载 |
| 2 | 多选与批量操作 | v1.1.0 | 多选、Shift 连选，复制/移动/删除逐项结果，同名不覆盖 |
| 3 | 文件夹上传 | v1.1.0 | 目录选择和拖放、相对路径、空目录、取消与重试 |
| 4 | 文件/目录打包下载 | v1.1.0 | 流式 ZIP，遍历和字节预算、失败中止、取消释放资源 |
| 5 | 后台任务中心 | v1.2.0 | 服务端复制等任务进度、取消、受控重试；v1.6.0 加入离线下载和后台 ZIP 结果；浏览器上传续传仍属后续扩展 |
| 6 | 全局文件名搜索 | v1.1.0 | 所选空间目录索引、完整路径与类型筛选，明确索引范围、时间和不完整状态 |
| 7 | 文本编辑 | v1.2.0 | 编辑现有文本、保存前冲突检测、失败保留草稿 |
| 8 | 音视频播放 | v1.3.0 | 浏览器可播放格式、本地字幕、播放列表和进度记忆；不承诺服务端转码 |
| 9 | Markdown 渲染与代码高亮 | v1.3.0 | 安全渲染、原文切换、目录 README |
| 10 | 分享链接 | v1.5.0 | 文件/目录范围、有效期、提取码和撤销，不泄露上游签名 URL |
| 11 | 多用户与目录权限 | v1.4.0 | 独立用户根目录及操作权限，同时覆盖网页/REST/WebDAV |
| 12 | 压缩包浏览 | v1.5.0 | 先支持 ZIP 内目录与单文件下载，限制解压资源 |
| 13 | 离线下载 | v1.6.0 | 公网 HTTP(S) 经 VPS 下载再上传 WPS；账号与目录绑定、字节进度、受控取消/重试；单任务 1 GiB、临时目录 2 GiB；30 分钟执行预算不保证撤回在途 WPS 上传；同时提供结果保留 1 小时的后台 ZIP |

需要真实账号接口证据的 WPS 专项能力暂不默认接入：Office/WPS 在线预览、回收站、历史版本恢复、WPS 原生文件夹复制。现有中继能力可继续用于目录复制。图片缩略图随 v1.3.0 发布；完整浏览器断点续传和更多压缩格式属于对应功能的后续扩展，不能以已有队列或分片接口宣称已实现。
